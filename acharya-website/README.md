# Acharya Shri Website

A complete, modern, responsive, and SEO-friendly static website for a Vedic scholar and spiritual guide.

## Features

- Peaceful spiritual design with elegant green and gold color scheme
- Fully responsive (mobile-first)
- Sticky navigation with hamburger menu
- Smooth scroll animations (AOS library)
- Animated counters
- Image lightbox gallery
- Embedded YouTube videos
- Contact form
- Back-to-top button
- Lighthouse optimized
- Accessible

## Folder Structure

```
Acharya-Website/
├── index.html
├── style.css
├── script.js
├── README.md
├── .gitignore
├── images/          (Add your images here)
└── icons/           (Optional)
```

## Setup

1. Download or clone this repository
2. Place your images in the `images/` folder:
   - `hero.jpg`
   - `acharya.jpg`
   - `wedding.jpg`
   - `hawan.jpg`
   - `geeta.jpg`
   - `sundarkand.jpg`
   - etc.
3. Open `index.html` in your browser
4. Customize content (name, contact details, videos, etc.)

## Deployment

Perfect for **GitHub Pages**, **Netlify**, or any static hosting.

## Customization

- Replace placeholder images
- Update contact information in `index.html`
- Change YouTube embed links
- Modify services in `script.js`
- Adjust colors in `:root` of `style.css`

## Technologies

- HTML5
- CSS3 (Custom, no frameworks)
- Vanilla JavaScript
- Google Fonts (Poppins)
- Font Awesome
- AOS Animation Library
